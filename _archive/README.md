# Historical material

These files are retained for reference and are not inputs to the CMake build.

- `legacy-root/Source`, `legacy-root/Resources`, `legacy-root/Tests`: older root copies; use the maintained files under `plugin/`.
- `legacy-root/tools/make_photos.py`: earlier image-preparation script; use `scripts/make_photos.py`.
- `output_notes_1`, `output_notes_2`: earlier sample-extraction experiments; the current runtime library is `samples/`.
- `photos`, `newpics`: original source photographs used by `scripts/make_photos.py` when regenerating plugin images.
- `Claude outputs`: earlier exported documents/packages.

Archived scripts and documents may contain historical paths. Current utility commands are documented in `scripts/README.md`.
